My personal blog! I'm not a front-end developer by any means, and I didn't want to get throughly familiar with .js and CSS and stuff for styling and whatnot, so I used the HUGO static site generator, with the Blowfish theme to make setting up a blog easier. Beyond basic parameter driven customisation of the theme, I also implemented my own custom theme, inspired by a Perlin Noise generator I implemented in python through pygame prior to this. 

Besides the custom theming, the content distribution is handled through obsidian. The source folder lives within my main Obsidian vault, and with the help of the terminal plugin, I can easily commit and push new content to the repository from the comfort of my vault, making content production very simple. You could make it simpler using the Git plugin, but I had some issues setting that up, and the terminal offers a more elegant solution in my opinion.

As for the purpose of the blog, its mainly just an archive of the projects I take on, and the cool things I learn on the way! I have a few other sections for book reviews and art, if I ever get to uploading any!
